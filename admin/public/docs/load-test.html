SDK 中台压测报告

记录验收口径与各场景重新测试结果。

验收口径

每轮分别记录压测有效性、服务指标和订单一致性，不用单一结论掩盖问题来源。严格整轮通过须同时满足适用的各项要求。

分类判定要求
压测有效性正常完成、未触发保护停止、未启动迭代为 0；启用采样时采样完整。未启动表示计划迭代没有发出，不等同于 HTTP 失败；出现时标记为目标负载未完整施加，不直接判定服务是原因。采样不完整时，依赖缺失数据的结论待确认。
服务指标每个稳压分钟完成请求量 ≥ 目标的 98%、HTTP p99 < 1,000 ms、业务失败率 < 0.1%；全程 HTTP 失败率和业务失败率分别 < 0.1%。同时记录失败绝对数量；必要时观察秒级吞吐和各接口延迟、错误，避免合计指标掩盖局部波动。
订单一致性仅适用于含订单的测试：完成订单迭代数大于 0，且与新增、支付、Mock 通知数完全一致，无无效订单。结束后按测试前约定的等待时间让通知排空，再核对最终状态；没有约定的等待时间时应注明，不能自行假设。

1,000 ms 为当前统一测试门槛，不代表生产 SLA。不同接口可在测试前另行约定延迟门槛；秒级吞吐和失败绝对数量目前作为观察项，不设新的统一否决阈值。
